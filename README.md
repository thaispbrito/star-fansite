# Star Fansite ⭐

Created while following the **Event Handling** lessons as part of the Ada Developers Academy Cohort 26.

## Getting Started 🚀

1. Before starting, run `npm install` or `npm i` to install dependencies.

2. Open up `index.html`, `src/index.js`, and `styles/style.css` to see the code.

3. Double-click the `index.html` file in the root of the repo to open it in a browser.

## Project Requirements ✨

Create a fan site based on a theme of your choice. For this project, **stars were chosen as the theme**.

## Website Design ⭐

- An appropriate title and top-level heading.
- A thematically appropriate background and text color scheme.

## Add Star Feature 🌟

- An **Add Star** button that allows users to add stars to the page.
- Each time the button is clicked, a new star element is added to the DOM and becomes visible.

## Star Counter 🔢

- An element that displays the total number of stars on the page.
- The counter updates every time the Add Star button is clicked.

## Theme Switcher 🌗

Create two themes that change the appearance of the website.

**1. Cosmic Night (Dark Mode) 🌌**
- Uses dark background.
- Features glowing white and golden stars.

**2. Celestial Day (Light Mode) 🌅**
- Uses light background.

Both themes should:
- Have a dedicated button to activate each theme.
- Use CSS classes to change the background and text colors of different HTML elements.
- Maintain the chosen theme's visual identity across both modes.
